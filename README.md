# 🪄 Wizard Duel — 손동작 마법 결투

웹캠으로 손 모양을 인식해 주문을 시전하는 1:1 해리포터풍 마법 결투 게임입니다.
손 인식은 [MediaPipe Hand Landmarker](https://developers.google.com/mediapipe/solutions/vision/hand_landmarker)를 사용합니다.

## 실행

카메라는 보안상 `localhost`(또는 HTTPS)에서만 켜집니다.

- Windows: `start.bat` 더블클릭 → 브라우저에서 `http://localhost:8000` 이 열립니다.
- 직접 실행: `python -m http.server 8000` 후 `http://localhost:8000` 접속

처음 실행할 때 손 인식 모델을 내려받으므로 인터넷 연결이 필요합니다.
노트북 내장 카메라를 자동으로 고르며, 카메라 화면 아래 메뉴에서 바꿀 수 있습니다.
카메라가 없으면 키보드 `1`~`6`으로 플레이할 수 있습니다.

## 주문서

| 손동작 | 주문 | 효과 |
|---|---|---|
| ☝️ 검지 | 스투페파이 (Stupefy) | 피해 12, 1.2초 기절, 적 영창 끊기 |
| ✌️ V 사인 | 익스펠리아르무스 (Expelliarmus) | 피해 8, 2.5초 무장 해제 |
| ✊ 주먹 | 인센디오 (Incendio) | 피해 10, 3초간 화상 |
| 🖐️ 손바닥 | 프로테고 (Protego) | 1.8초 방어막, 맞기 직전 0.35초 안에 펴면 반사 |
| 👍 엄지 척 | 에피스키 (Episkey) | 체력 18 회복 |
| 🤘 락 사인 | 익스펙토 패트로눔 (Expecto Patronum) | 궁극기, 피해 30, 방어막 관통 |

## 규칙

- 손 모양을 잠깐 유지하면 주문이 나갑니다. 같은 주문을 다시 쓰려면 손을 한 번 풀었다가 다시 만드세요.
- 주문마다 마나와 재사용 대기시간이 있습니다.
- 적은 저주를 쓰기 전에 영창 게이지를 채웁니다. 막거나, 반사하거나, 기절·무장 해제로 끊으세요.
- 양쪽 주문이 공중에서 부딪히면 상쇄됩니다. 패트로눔은 상대 주문만 지우고 계속 날아갑니다.
- 난이도: 견습생 / 죽음을 먹는 자 / 어둠의 군주
